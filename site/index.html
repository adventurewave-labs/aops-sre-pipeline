The autonomous SRE pipeline
that fixes itself.

A.O.P.S. catches a Prometheus alert, scans the cluster with Popeye, reasons through the findings with a Dify-style agent backed by Ollama, and posts a Slack card with the exact kubectl commands to fix it — all open-source, all self-hosted, all air-gapped.

Architecture

Six services, one alert-driven chain. Every component is replaceable.

Six services, every one replaceable

Each component is a thin Python service (or container). Swap any of them for your preferred alternative without touching the others.

K8s

mock-k8s-api

:8001

Mock kube-apiserver returning 6 broken resources in the payment-prod namespace. Bearer-token auth enforced. Swap for your real apiserver by setting MOCK_K8S_URL.

Replaces: your kube-apiserver
POP

popeye-scanner

:8004

14 Popeye-compatible analyzers (NO-002, DPL-000, DPL-001, POP-001/002, MEM-001, ING-001, PVC-001/002). Rules-based, deterministic — no hallucination.

Replaces: K8sGPT
DFY

dify-lite

:8002

FastAPI agent mimicking Dify.ai's OpenAI-compatible chat-completions API, with a 2-round tool-calling loop. Auto-falls back to deterministic stub when Ollama is down.

Replaces: Dify.ai
OLL

ollama

:11434

Local LLM runtime serving qwen2.5:0.5b by default. Swap to llama3.1:8b for higher-quality reasoning. CPU-only is fine; GPU makes it faster.

Replaces: any OpenAI-compat API
SLK

mock-slack

:8003

Receives the remediation card via HTTP, renders an auto-refreshing Slack-card HTML page at /, persists every alert at /alerts.json. No Slack creds needed.

Replaces: real Slack incoming-webhook
N8N

n8n-runner

:5678

Lightweight workflow executor that loads the same aops-workflow.json that real n8n imports. Replaces with n8nio/n8n:latest in 30 seconds.

Replaces: n8n (official image)

Two ways to run it

Sandbox mode (no Docker) for quick demo · Docker mode for real Ollama.

SANDBOX no Docker · stub backend · 23 ms 
# clone + start all 5 services as Python processes
git clone https://github.com/adventurewave-labs/aops-sre-pipeline.git
cd aops-sre-pipeline

# bring up the stack (no Docker needed)
./run.sh up-no-ollama

# fire the PaymentAPIHighErrorRate alert
./run.sh alert

# view the rendered Slack card in a browser
open http://localhost:8003

# stop everything
./run.sh stop
DOCKER real Ollama · qwen2.5:0.5b · 1.5-4 s 
# bring up the full stack with real Ollama
docker compose up -d

# the ollama-pull sidecar auto-pulls qwen2.5:0.5b
docker compose logs -f ollama-pull

# run the UAT matrix against the live stack
docker compose exec n8n-runner \
    python3 scripts/run_uat.py

# swap to a bigger model on a GPU host
OLLAMA_MODEL=llama3.1:8b docker compose up -d
